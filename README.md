# Network & Port Scanner

A lightweight Python tool designed to perform rapid TCP port scans across targeted network hosts using multi-threading.

## Key Features
- **Concurrent Scanning:** Uses Python's `concurrent.futures` to scan multiple ports simultaneously.
- **Service Detection:** Identifies open TCP ports (SSH, HTTP, HTTPS, DB ports).
- **Socket Utility:** Built on low-level Python `socket` API for lightweight execution.

## Usage
1. Clone the repository: `git clone https://github.com/YOUR_USERNAME/network-port-scanner.git`
2. Run the script: `python scanner.py`
